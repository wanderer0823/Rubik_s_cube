# 剧情对话系统使用说明

本系统使用纯 JSON 编辑新手引导数据。每个房间对应一个 JSON 文件；点击开始游戏后，房间实例在 `RoomInstanceManager` 中加载完成会自动尝试触发对应对话。

## 相关脚本

```c
Assets/Csharp/GameManager/Logic/Tutorial/DialogueManager.cs		//状态机;维护队列，控制是自动继续（Delay）还是卡住等事件（WaitForEvent），以及条件开关（Flag）
Assets/Csharp/GameManager/Logic/Tutorial/DialogueStepData.cs	//数据容器
Assets/Csharp/GameManager/Logic/Tutorial/DialogueUI.cs			//表现层；UI显示相关
Assets/Csharp/GameManager/Logic/Tutorial/TutorialController.cs	//总调动
```



## 文件位置

JSON 文件统一放在：

```text
Assets/StreamingAssets/TutorialDialogues/
```

文件名规则：

```text
room_{房间ID}.json
```

系统会优先读取 `.json`。如果同名 `.json` 不存在，也会尝试读取 `.js`，方便临时沿用 `room_43.js` 这类文件名。

例如 43 号房间：

```text
Assets/StreamingAssets/TutorialDialogues/room_43.json
```

## JSON 格式

```json
{
  "roomId": 43,
  "steps": [
    {
      "speaker": "Guide",
      "text": "这里是 43 号房间的新手引导示例。",
      "color": "#FFFFFFFF",
      "stepType": "Text",
      "eventId": "",
      "delayTime": 0,
      "requiredFlag": "",
      "completeFlag": "room43_intro_seen"
    }
  ]
}
```

字段说明：

- `roomId`：房间 ID，用于自检；实际读取由文件名决定。
- `speaker`：说话人。
- `text`：显示文本。
- `color`：HTML 颜色字符串，例如 `#FFFFFFFF`。
- `stepType`：步骤类型，可填 `Text`、`WaitForEvent`、`Delay`、`ShowTips`。
- `eventId`：事件 ID，`WaitForEvent` 使用，例如 `LockWASD`。
- `delayTime`：延迟秒数，`Delay` 使用。
- `requiredFlag`：播放该步骤前必须拥有的标记。
- `completeFlag`：该步骤完成后写入的标记。

## 触发规则

`RoomInstanceManager` 在当前房间 prefab 实例化、归零位置、设置旋转后，会调用：

```csharp
TutorialController.Instance.TryStartRoomDialogue(currentRoomId);
```

`TutorialController` 会读取：

```text
Application.streamingAssetsPath/TutorialDialogues/room_{roomId}.json
```

如果文件不存在，会安静跳过。只有点击开始游戏且对话成功开始后，当前房间 ID 才会被记录为已触发。

每个房间每局游戏只触发一次；重启游戏后会重新计算。

## 步骤类型

- `Text`：普通文本，点击后继续。
- `ShowTips`：提示文本，点击后继续。
- `Delay`：显示当前内容后自动等待 `delayTime` 秒，然后继续。
- `WaitForEvent`：进入阻塞状态，等待外部调用完成事件后继续。

## WaitForEvent

`TutorialController` 目前预留了两个事件 ID：

- `LockWASD`
- `UnlockWASD`

43 号房间教程已经接入的事件 ID：

- `OpenBag`：背包打开后完成。
- `EnterCube`：切换到魔方视角 `View2` 后完成。
- `EnterCubeAgain`：再次切换到魔方视角 `View2` 后完成。
- `RightDragCompleted`：右键拖动查看魔方并松开后完成。
- `LeftDragCompleted`：左键拖动空白处旋转魔方整体，并在整体回正完成后完成，由 `CubeRotateController` 触发。
- `ExitCube`：切回房间视角 `View3` 后完成。
- `LockWASD`：锁定 WASD 移动并立刻继续。
- `UnlockWASD`：解除 WASD 移动锁定并立刻继续。

`LockWASD` 和 `UnlockWASD` 已接到 `PlayerInputManager` 的移动锁，只影响 WASD 移动，不影响 Tab、F 和鼠标操作。

其他事件默认只输出日志，并保持队列阻塞。外部逻辑完成后调用：

```csharp
TutorialController.Instance.CompleteTutorialEvent("YourEventId");
```

或：

```csharp
DialogueManager.Instance.CompleteWaitEvent("YourEventId");
```

## 场景挂载

1. 场景中需要有 `DialogueManager`。
2. 对话 UI 根物体上挂 `DialogueUI`，并绑定：
   - `Root`
   - `Speaker Text`
   - `Dialogue Text`
   - `Click Button`
3. 场景中需要有 `TutorialController`，绑定 `DialogueManager` 和 `DialogueUI`。
4. 场景中已有的 `RoomInstanceManager` 会在房间加载后自动尝试触发对应 JSON；开始游戏前不会播放。
