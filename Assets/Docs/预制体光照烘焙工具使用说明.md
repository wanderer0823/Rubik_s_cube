# Prefab Lightmap Tool 使用说明

## 用途

这个工具用于让动态生成的 Prefab 使用自己对应的烘焙光照贴图。生成完成后，Prefab 根节点会带上 `PrefabLightmapBinding` 组件；运行时只要实例化这个 Prefab，就会自动恢复对应的 Lightmap。

这个方案的光影表现是“烘焙光影跟随物体旋转”。也就是说，光照结果像贴图一样属于 Prefab 自身，不代表世界空间里固定方向的太阳光。

## 美术烘焙准备

1. 新建或打开一个专门用于烘焙的场景。
2. 把目标 Prefab 放到场景里，并确认它的层级结构和最终 Prefab 一致。
3. 需要参与烘焙的模型勾选 Static / Contribute GI。
4. 烘焙灯光设置为 Baked 或 Mixed。
5. 完成灯光、材质、UV2、静态标记设置后执行 Unity 烘焙。

注意：烘焙后不要再改参与烘焙物体的层级、Renderer 数量、UV2、缩放比例。如果改了，需要重新烘焙并重新生成 LightmapData。

## 生成和绑定

1. 打开菜单 `Tools/Lightmaps/Prefab Lightmap Tool`。
2. 在 `Prefab` 字段选择要绑定光照的 Prefab 资源。
3. 如果当前打开的就是烘焙场景，勾选 `Use Current Scene`。
4. 如果要从其它场景读取烘焙结果，取消 `Use Current Scene`，在 `Baked Scene` 里选择对应场景。
5. `Output Folder` 默认使用 `Assets/Resources/PrefabLightmaps`，通常保持默认即可。
6. 保持 `Bind To Prefab` 勾选。
7. 点击 `Generate Lightmap Data`。

工具会生成或更新 `{PrefabName}_LightmapData.asset`，并把 `PrefabLightmapBinding` 添加到 Prefab 根节点上。

## 运行时验证

1. 在任意运行场景中动态生成该 Prefab。
2. 确认 Prefab 生成后不需要额外挂测试器或扫描器。
3. Prefab 上的 `PrefabLightmapBinding` 会在 `OnEnable` 时自动应用光照。
4. 如果生成多个相同 Prefab，Lightmap 贴图不会重复追加。

## 常见问题

- 生成后没有光照：确认烘焙场景里对应对象已有有效 Lightmap，并且生成时找到了正确 Prefab。
- 控制台提示 Renderer 找不到：Prefab 层级或 Renderer 名称和烘焙场景不一致，需要重新放置并烘焙。
- 修改了模型或灯光：重新烘焙，再重新生成 LightmapData。
- 想手动触发：可以调用 `PrefabLightmapBinding.ApplyNow()`。

## test1/test2 快捷入口

菜单 `Tools/Lightmaps/Generate Test1 And Test2 Data` 仍保留，用于当前测试资源：

- `Assets/Source/test/test1.prefab` 对应 `Assets/Scenes/4.unity`
- `Assets/Source/test/test2.prefab` 对应 `Assets/Scenes/4 1.unity`

该入口也会自动把数据绑定到对应 Prefab。
